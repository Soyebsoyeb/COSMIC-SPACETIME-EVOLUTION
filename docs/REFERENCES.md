# References

Every entry carries a verification status:

* **verified**: existence, authors and identifier were confirmed by a web search during development of this repository.
* **recalled**: cited from the author's recollection of the literature; the existence of the work is well established, but bibliographic details (pages, years) and, where noted, numerical coefficients taken from it were **not** re-checked against the source. Please verify before citing.

No DOI or arXiv number is given unless it was verified.

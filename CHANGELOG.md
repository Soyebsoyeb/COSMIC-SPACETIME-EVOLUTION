# Changelog

All notable changes are documented here. The format follows Keep a Changelog; versions follow Semantic Versioning.

## [0.1.0] - 2026-10-16

### Added

* FLRW background with CPL dark energy, curvature, radiation; age, distances, horizons, deceleration parameter.
* Early universe: $g_*(T)$ thermal history, BBN relations and backend interface (no network), Peebles recombination, slow-roll inflation (quadratic and Starobinsky), perturbative reheating.
* Perturbations: Mukhanov-Sasaki scalar and tensor mode solver, linear growth factor.
* Structure: BBKS and Eisenstein-Hu no-wiggle transfer functions, $\sigma_8$, Press-Schechter and Sheth-Tormen mass functions.
* Future scenarios with conditional fate classification.
* Numerical convergence and uncertainty tools.
* 23 publication figures (PNG and PDF) with CSV datasets, key-result tables, parameter sweeps.
* 113 unit tests; 13-check validation report.
* Documentation (15 documents), notebooks, CI workflow definitions.
